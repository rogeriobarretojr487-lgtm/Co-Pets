--CO-PETS--           

Fintech baseada no projeto academico junto a FIAP.

O Co_Pets é um projeto de Fintech criado pensando nos tutores que apresentam dificuldades em cuidar das reservas financeiras para seus pets e seus cuidados como alimentação, pet shop, remedios, emergencias, entre outros...
 Como estudante de tecnologia e apaixonado por animais eu decidi criar e investir meu tempo e conhecimento nesse projeto visando todos que precisam ter mais controle financeiro para ajudar seus pets. 

Para utilizar o sistema acesse o arquivo Main.java, que é o arquivo execultavel do projeto.
